# Drone Simülatörü · Mavi Kanat

DJI Mini 5 Pro ve Robinson R44 uçuş simülatörü. Dünya, Everest, Mars, Titan ve Venüs'te gerçek fiziğe dayalı uçuş.

## İndir ve oyna
1. Sağdaki **Releases** bölümünden en yeni sürümün `DroneSimulatoru_X.Y.Z.zip` dosyasını indir.
2. Zip'i aç, `DroneSimulatoru_X.Y.Z.exe` dosyasını çalıştır. Kurulum gerekmez.

Gereksinim: Windows 10/11 (Microsoft Edge WebView2 — Windows 11'de hazır gelir).

> Windows "Bilgisayarınız korundu" uyarısı gösterirse: **Ek bilgi → Yine de çalıştır**. Program imzasız olduğu için bu uyarı çıkabilir.

Her sürüm ayrı ayrı indirilebilir; eski sürümler de Releases'ta durur.
